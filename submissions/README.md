# 제출 폴더

실행 도구가 만든 `실행ID.zip`을 이 폴더에 저장하고 본인의 `students/참가자번호` 브랜치에 푸시합니다.

`python lab.py submit`이 파일 생성, 커밋과 push를 처리합니다. 직접 Git을 사용하는 경우에도 같은 폴더와 브랜치를 사용합니다. ZIP의 내부 파일이나 측정값을 수동으로 바꾸지 않습니다.

반복 실행 기록을 각각 유지합니다. 기본 지침 실행을 개선 결과로 덮어쓰지 않습니다.

채점 결과는 `results` 브랜치에 기록하며, `python lab.py sync`로 로컬 결과 화면에 반영합니다. 이 폴더에는 정답 코드, 인증 정보, 가상환경 폴더를 넣지 않습니다.
